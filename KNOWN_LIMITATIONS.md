# Known Limitations

**Snapshot date:** 2026-04-15

- This is a self-hosted prototype; production deployment needs environment-specific security review.
- Frontend coverage is lighter than backend coverage.
- The validation API depends on published versions; draft/live collaboration behavior should be reviewed before team use.
- AI schema suggestions are optional and depend on user-provided model configuration.
- Integration/webhook surfaces should be treated as planned or experimental unless explicitly documented as tested.
- No hosted multi-tenant service is provided by this repository.
