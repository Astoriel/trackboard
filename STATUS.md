# Project Status

**Status:** Active product prototype  
**Snapshot date:** 2026-04-15  
**Primary audience:** product analytics teams that need a self-hosted tracking plan workspace.

`trackboard` is a full-stack tracking plan manager with a FastAPI backend, Next.js frontend, schema validation, versioning, merge-review flows, API keys, and generated SDK snippets. It is more than a static portfolio mockup, but it is still a prototype and should be evaluated with that boundary in mind.

## Current Confidence

- Working: local Docker/dev setup, API models, auth flow, tracking plan CRUD, validation engine, version snapshots, merge request workflow, frontend dashboard pages.
- Planned: hardened hosted deployment, broader integration catalog, production-grade observability, stronger frontend regression coverage.
- Not claimed: Segment Protocols parity, enterprise SSO, high-scale production SLA.
